# Jiayi Qian's academic website

Personal research website at [jiayi-19.github.io](https://jiayi-19.github.io/), hosted with GitHub Pages.

- `index.html`: biography, research interests, publications, news, and experience.
- `homepage.css`: responsive homepage styling, motion preferences, and print styles.
- `script.js`: progressive enhancement for research topic filters. All content remains readable without JavaScript.
- `data/CV_jiayi.pdf`: current CV. Keep `data/CV-Jiayi.pdf` identical for existing links.
- `images/`: profile and research figures.

There is no build step. Preview with `python3 -m http.server 8000`, then open `http://localhost:8000`.

GitHub Pages publishes from the root of `master`. Keep submissions under review clearly labeled and separate from published or workshop papers.

Originally based on [Jon Barron's academic website](https://github.com/jonbarron/jonbarron_website). Legacy project pages and `stylesheet.css` are retained separately from the homepage.
